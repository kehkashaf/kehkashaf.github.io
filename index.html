01 — About

A short version of the story

I’m Kehkasha Dumasia — a student at IIT Kharagpur who likes turning a rough idea into something people can actually open in a browser.

I started the way most people do: curious, a little intimidated, and convinced everyone else already knew the secret. It turns out there isn’t one. There’s just the loop — build a small thing, break it, read the error, fix it, and end up understanding something you didn’t an hour ago.

What keeps me going is the moment an idea stops being a sketch and starts responding to a click. I care about work that is clear to read, kind to the person using it, and honest about what it does. This site is the first entry in a list I intend to keep adding to.

04 — Journey

How this page came to exist

  1. Decide what is worth a page

    An idea with real details beats a generic template every time. Mine was simple: a place that is actually mine.

  2. Write the code

    Structure in HTML, look in CSS, life in JavaScript. Three files, one page, no magic.

  3. Put it on GitHub

    A repository gives the work a home: a link anyone can read, a full history of every version, and a door for other people to contribute.

  4. Publish it live

    GitHub Pages serves the repository straight to the web — so the code and the site stay the same thing, kept in sync by every commit.
